Experiment-124

Information

Experiment-124 is like John Doe. Dr.███████████ has found a way to create the same myth, but it has a cost: to sacrifice someone. So we kidnapped Ptitomboss (our target), and we used the Necrabloxicon to do it. It kind of worked, but some faulty code appeared and corrupted our test subject. We tried to communicate with it, but it did not work. Also, they seem to be following something... like a voice. If we can find a way to make them follow our commands, we can use it as a weapon.

Side note: The old name of this experiment was Experiment-Ptitomboss.

Status : Alive

Ability

We have done several tests, and this is what we conclude:

  • Super strength: it can lift up to 30 kg of steel.
  • It can shapeshift. We see that its avatar always changes, but it can be easily identified by the corrupt code that is still there.
  • It walks and runs faster than an average human.
  • Its corruption has killed two of our immortal experiments.
  • It is a little bit more intelligent than an average human.

Those are the things we are unsure about:

  • We haven't run a test to see if it can change gender when it changes appearance.
